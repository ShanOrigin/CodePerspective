
 Reminder :  This all below Commands only work in Project root ( Cpp)  directory so first check where you are in directory 

 Commands

 /* Server Commands */

 "npm run s"              ||  only starts backend server
 "npm run server"         ||  only starts backend server

 /* React Commands  */

 "npm run r"              ||  only start frontend react app  
 "npm run react"           ||  only start frontend react app


 /* Project Commands   */                                                          
 "npm start"              ||  starts both backend server and frontend react app                 
 "npm run QueenMedusa"    ||  starts both backend server and frontend react app ( same     as npm start )

 "npm run DNM"            ||  delete all node_modules from Project which inlcudes database , r    eact , Project node_modules

 "npm run initial"        ||  install all node_modules in Project which inlcudes database     , react , Project node_modules and simultaneously run Project ( note : only use     this command when you want to install all node_modules and run project first t    ime , then use any one following "Project Commands" command afterwards to run p    roject )
